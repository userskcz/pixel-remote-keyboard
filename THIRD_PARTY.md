# Third-party notices and provenance

## Inspiration

[Wearboard by theGeekyLad](https://github.com/theGeekyLad/wearboard) inspired the initial personal prototype's phone/watch editing flow. The inspected upstream revision was f1a97d22371995f6af736b31631c2b6ff5d997c5; no explicit source license was found in that checkout.

The public 0.3 source package does not vendor or compile upstream source, Compose screens, assets, wrappers, or its protobuf payload adaptation. The previous WearboardPayload implementation has been removed. This release uses this project's own PRK1 length-prefixed UTF-8 packet and independent native Android UI, session logic, IME, listener service, and transport integration.

This acknowledgment does not relicense Wearboard or imply endorsement. The application's generic request/response architecture uses Google's documented Wearable Data Layer APIs.
