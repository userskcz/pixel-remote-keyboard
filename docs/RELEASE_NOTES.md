# Pixel Remote Keyboard 0.3.0-beta.2

Type comfortably on your Android phone and insert text into a Wear OS text field.

This beta adds native crown scrolling, an English interface, a scroll indicator, Android 15+ scroll feedback, and public build/release infrastructure.

Install both companion APKs from the same release. Update both when moving from 0.1.x or 0.2.x: the application protocol has changed. In-place updates also require the same signing certificate.

APK roles:
- pixel-keyboard-phone.apk — install on your Android phone.
- pixel-keyboard-watch.apk — install on your Wear OS watch.
- SHA256SUMS.txt — verify downloads.

Known limits: standard input fields only, paired connectivity required, 60 KB packet limit, English UI. Complete hardware verification of this beta is pending. No production-signed public release has been published as part of local preparation.
